# [0.6.0] - 2/9/2026

## Modding

- MINIMUM SUPPORTED MOD API VERSION: `0.1`
- Added support for JSON CHARACTERS!

## General

- Added note fading for when the strumline passed the note (Also Yoinked from psych hehehehaw)
- Added hitsounds to the chart editor (Yoinked from psych hehehehe)
	- Added `hitsound_opponent` and `hitsound_player` save fields
	- Added "Play Hit Sound for Player notes" and "Play Hit Sound for Opponent notes" checkboxes to Chart editor "Notes" tab
- When pressing `7` on the Main Menu it will now send you to the chart editor
- Fixed Haxeflixel splash not being skipped

## Technical

- `-DINSTA_SAVE` is now auto-enabled on debug and indev builds
- Added `-DSKIP_SPLASH` define
	- Auto-enabled on debug and indev builds
- Fixed when in chart editor when you would erase a note on one side and there was the same note on the other side it would remove both notes
- `koya.frontend.scenes.play.PlayState.SONG_DIFFICULTY` is now set to the loaded songs difficulty and setting it via another state loading into it is unrequired.
	- This fixes the variable not being set by the chart editor and thus the pause menu thinking you're on the normal difficulty
- Added `-DROOT_SAVE` define : when using `-DINSTA_SAVE` it will save to the root directory
	- Auto-enabled for debug or indev builds
- Added `hidden` field to Week JSONS : This will prevent the week from appearing in STORY MODE.
	- Added Failsafe measures when loading into storymode for if there were errors reading the week JSON
- Fixed Charting State `curSong` / Song name when saving not changing when you change the song name and reload the audio
- Added `-DTASK_CREATE_COMPILED_CHANGELOG` define : Runs `CreateCompiledChangelog`
	- Auto-run on `debug` or `indev` builds
- `CHANGELOG.md` is now generated from smaller changelog files in `dev/changelogs/` via a new task (prebuild) script : `CreateCompiledChangelog`
